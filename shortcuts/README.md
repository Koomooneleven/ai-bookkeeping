# Apple 快捷指令配置指南

## 第 1 步：创建快捷指令

在 iPhone 上打开 **快捷指令** App，按以下步骤创建：

1. 点击右上角 **+** 新建快捷指令
2. 点击顶部标题，命名为 **"AI 自动记账"**
3. 按下方顺序添加操作：

### 添加操作步骤

| 序号 | 添加的操作 | 设置 |
|------|-----------|------|
| ① | **"要求输入"** | 操作类型选"文本"，提示文字填："输入消费内容" |
| ② | **"URL"** | 设为：`https://你的域名/api/transactions` |
| ③ | **"获取 URL 内容"** | 方法：**POST**，请求体：**JSON**，展开设置：<br>- 添加头部 `Content-Type`: `application/json`<br>- 添加头部 `X-API-Key`: `你设置的API_KEY`<br>- 请求体选"词典"，添加字段 `text` 值为 ①的输入 |
| ④ | **"获取词典值"** | 对 ③ 的响应，获取 `data` |
| ⑤ | **"获取词典值"** | 对 ④ 的结果，获取 `item_name` |
| ⑥ | **"获取词典值"** | 对 ③ 的响应，获取 `success` |
| ⑦ | **"如果"** | 条件：⑥的值 是 `true` |
| ⑧ | → 在"如果"内添加 **"显示通知"** | 通知文字：`✅ 已记录：⑤的结果` |
| ⑨ | → 在"否则"内添加 **"显示通知"** | 通知文字：`❌ 记录失败` |

## 第 2 步：配置背面双击

1. 打开 iPhone **设置** → **辅助功能** → **触控**
2. 滑到底部 → **背面轻点**
3. 选择 **"轻点两下"** → 在列表中找到 **"AI 自动记账"** 并选中

## 第 3 步：使用

- 付款后，**双击手机背面**
- 弹出文本框，输入消费内容（如"麦当劳午餐35元"）
- 点击"完成"，自动发送到服务器解析
- 收到通知：`✅ 已记录：麦当劳午餐 CNY 35.0`
