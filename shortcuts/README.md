# Apple 快捷指令配置指南

## 方案 A：截屏自动记账（推荐 🔥）

付款后停留在支付成功页面，双击背面 → 自动截屏 → OCR识别 → AI解析 → 记录。

### 创建步骤

1. 打开 **快捷指令** App → 右上角 **+** → 命名为 **`AI自动记账-截屏`**
2. 按顺序添加以下操作：

| # | 搜索添加 | 设置 |
|---|---------|------|
| ① | **截屏** | 保持默认 |
| ② | **等待** | 设为 1 秒 |
| ③ | **获取最新截屏** | 数量改为 1 |
| ④ | **从图像提取文本** | 保持默认 |
| ⑤ | **URL** | `https://ai-bookkeeping-production-87a3.up.railway.app/api/transactions` |
| ⑥ | **获取 URL 内容** | 方法: POST<br>头部: `X-API-Key` → `jizhang2026`<br>请求体: JSON → 字段 `text` → 选④的输出变量 |
| ⑦ | **显示通知** | 内容选⑥的响应 |
| ⑧ | **删除照片** | 保持默认（清理截屏） |

> ⚠️ 关键：第⑥步 `text` 字段的值必须是**点击选择蓝色变量**「从图像提取文本的内容」，不是打字输入！

3. 绑定背面双击：**设置 → 辅助功能 → 触控 → 背面轻点 → 轻点两下 → AI自动记账-截屏**

### 使用流程

```
付款 → 停留在支付成功页 → 双击背面 → 自动截屏识别 → 通知"已记录"
```

## 方案 B：手动输入（备用）

偶尔需要手动输入时使用（比如现金支付）。

### 创建步骤

| # | 操作 | 设置 |
|---|------|------|
| ① | **要求输入** | 类型: 文本，提示: `输入消费内容` |
| ② | **URL** | `https://ai-bookkeeping-production-87a3.up.railway.app/api/transactions` |
| ③ | **获取 URL 内容** | 方法: POST<br>头部: `X-API-Key` → `jizhang2026`<br>请求体: JSON → 字段 `text` → 选①的输出变量 |
| ④ | **显示通知** | 内容选③的响应 |

> ⚠️ 同样：`text` 字段值必须**点击选择**蓝色变量「提供的输入」，不打字。

---

## 两种方案可共存

创建两个快捷指令，背面双击绑定截屏版。手动版放在桌面小组件或 Siri 调用。
