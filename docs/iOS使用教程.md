# AI 记账系统 — iPhone 使用教程

## 概述

付款后双击手机背面 → 自动截屏识别 → AI 解析记录。也支持手动输入。

---

## 一、安装快捷指令

### 方案 A：截屏自动记账（推荐）

| 步骤 | 操作 | 截图说明 |
|------|------|----------|
| 1 | 打开 **快捷指令** App | 桌面找到紫色图标 |
| 2 | 点右上角 **+** 新建 | |
| 3 | 点顶部标题 → 重命名为 `AI记账` | |
| 4 | 搜索添加 **截屏** | 底部搜索框输入"截屏" |
| 5 | 搜索添加 **从图像提取文本** | ⚠️ 关键：点操作块上的输入来源，选择①截屏的输出 |
| 6 | 搜索添加 **URL** | 填入 `https://ai-bookkeeping-production-87a3.up.railway.app/api/transactions` |
| 7 | 搜索添加 **获取 URL 内容** | 展开设置：<br>• 方法 → `POST`<br>• 添加头部 → 键 `X-API-Key` 值 `jizhang2026`<br>• 请求体 → `JSON`<br>• 添加字段 → 键 `text`，值**点击选择**⑤提取文本的输出变量 |
| 8 | 搜索添加 **显示通知** | 可选设通知文字 |
| 9 | 搜索添加 **删除照片** | 防止截屏堆积 |
| 10 | 点右上角 **完成** | |

#### ⚠️ 关键步骤图解

**第 5 步 — 连接 OCR 输入：**
```
点击「从图像提取文本」操作块上的「输入」区域
→ 在弹出的选择器中，选择「截屏」的输出
（截屏 → 提取文本，形成一条连线）
```

**第 7 步 — 设置请求体 text 字段：**
```
在「获取 URL 内容」的 JSON 字段中：
→ 键填 text
→ 点值区域 → 选择「从图像提取文本的内容」
（必须是蓝色胶囊变量，不是打字输入！）
```

> ❌ 打字输入 "提供的输入" 四个字 → 错误
> ✅ 点击选择蓝色胶囊变量 → 正确

## 二、绑定背面双击

1. 打开 **设置** → **辅助功能** → **触控**
2. 滑到底部 → **背面轻点**
3. 选择 **轻点两下**
4. 在列表中找到 **AI记账** 并勾选

> 设置路径：设置 → 辅助功能 → 触控 → 背面轻点 → 轻点两下

## 三、日常使用

### 截屏记账流程

```
付款完成 → 停留在支付成功页面
         → 双击手机背面
         → 自动截屏 → OCR识别 → 记录
         → 通知弹出确认
```

## 五、常见问题

**Q: 双击背面没反应？**
A: 检查 设置→辅助功能→触控→背面轻点 是否正确绑定。

**Q: 截屏识别不准确？**
A: 确保停留在"支付成功"页面，不要让其他弹窗遮挡金额或商家名。

**Q: 通知显示错误？**
A: 检查快捷指令中 URL 和 API Key 是否正确。

**Q: 如何修改 API Key？**
A: 在快捷指令编辑界面，找到"获取 URL 内容"，修改 `X-API-Key` 头部。
